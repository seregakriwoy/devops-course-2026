# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
* **Объём памяти:** 2048 МБ
* **Количество ядер:** 2
* **Объём диска:** 25 ГБ (динамически расширяемый)

## 2. Сетевые интерфейсы
* **Адаптер 1 (NAT):** Полученный адрес: `10.0.2.15`. Назначение: доступ в интернет, обновление пакетов.
* **Адаптер 2 (Host-only):** Полученный адрес: `192.168.56.101`. Назначение: прямой доступ с хостовой системы (управление, доступ к веб-серверу в лабе №6).

## 3. Правило проброса портов
* **Порт хостовой системы:** 2222
* **Порт гостевой системы:** 2222

## 4. Учётные записи
* **student:** входит в группу `sudo`, аутентификация по паролю (используется для первичной настройки).
* **devops:** входит в группу `sudo`, аутентификация по SSH-ключу (`~/.ssh/devops_vm` на хосте).

## 5. Служба SSH
* **Порт:** 2222
* **Расположение файла конфигурации:** `/etc/ssh/sshd_config.d/99-hardening.conf`
* **Изменённые директивы и их значения:**
  * `Port 2222` (изменен стандартный порт)
  * `PermitRootLogin no` (запрещен вход под root)
  * `PasswordAuthentication no` (отключен вход по паролю)
  * `PubkeyAuthentication yes` (разрешен вход по ключам)
  * `MaxAuthTries 3` (ограничено число попыток)
  * `AllowUsers devops` (разрешен вход только пользователю devops)

## 6. Правила межсетевого экрана (UFW)
* **Политика по умолчанию:** `deny incoming`, `allow outgoing`
* **Перечень правил:**
  * `2222/tcp` LIMIT (SSH rate-limited)
  * `80/tcp` ALLOW (HTTP)
  * `443/tcp` ALLOW (HTTPS)

## 7. Снимки состояния
1. `01-clean-install` — создан после установки ОС и обновления пакетов.
2. `02-keys-configured` — создан после настройки SSH-ключей и файла `config` на хосте.
3. `03-ssh-hardened` — создан после ужесточения конфигурации SSH.
